# Sdot

Talk to your running [pi](https://pi.dev) coding-agent session from your Android phone, hands-free, like a phone call.

Sdot is not another agent. It gives your existing pi session ears and a mouth:

- **`extension/`** — a pi extension that runs inside your session. It streams what the agent writes and injects what you say.
- **`android/`** — a native Android app that turns your voice into text and the agent's replies into speech, on the device.

Documentation is in progress.
